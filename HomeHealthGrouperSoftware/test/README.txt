		--  Home Health Grouper Software (HHGS)  --
					Distribution pack

This folder includes grouper test file(s) with expected results.

	1. TestDataV<VVSYY>.txt - file with new content test cases and expected HIPPS results (Grouper Return Code = 0)
	2. TestDataV<VVSYY>_GRC.txt - file with irregular test cases and expected Grouper Return Code <> 0

Notes:
(a) In file names: 'VV' is software version, 'S' is software subversion, 'YY' - last 2 digits of year.
(b) The expected results located from offset position 549 of each test record.
