		--  Home Health Grouper Software (HHGS)  --
			Distribution pack

This distribution pack includes all the source code, source documentation, user manuals,
and test data for Home Health Grouper Software


To install and run the Home Health Grouper Software (batch module) please perform
the following steps:

(1) Make sure you have Java 17 or higher installed on your computer; Java 8 no longer applies
(2) Unzip this Home Health Grouper Software pack into desirable location
(3) Navigate to the 'HomeHealthGrouperSoftware\bin' folder
(4) Run the 'runGrouperTest.bat'
(5) Navigate to the 'HomeHealthGrouperSoftware\test' folder
(6) You will see the 'TestDataV<VVSYY>_OUT.txt' file with the grouping
	results *

*Notes:
(a) Please check the 'runGrouperTest.bat' file for generating output record 
	only vs. full record (input + output)
(b) Where 'VV' is software version, 'S' is software subversion, 'YY' - 
	last 2 digits of year.
